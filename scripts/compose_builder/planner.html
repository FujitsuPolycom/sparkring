1 · Sparks

Two Sparks form a pair; three to eight form a ring. Position 0 is Node A. The cables number the others.

2 · Models and where they run

Automatic selects the first free aligned group from Node A after reserving explicit groups. The command pins that choice with --on. Overlapping groups block all commands.

3 · Installation

A new installation asks before changes. Plan only requires SparkRing to be installed already.
