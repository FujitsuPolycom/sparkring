# MiMo-V2.6-Flash-RL on two Sparks, 2026-09-22

Status: **implemented, not qualified**. One site, one day, one benchmark
script per configuration. Profile
[`mimo-v26-flash-rl-tp2`](../../../profiles/mimo-v26-flash-rl-tp2/README.md);
runtime contract [image.json](../../../runtime/mimo-v26-flash/image.json).

## Conditions

Two GB10 Sparks on one direct cable. Published image
`ghcr.io/fujitsupolycom/sparkring@sha256:26c366af…` (vLLM
`0.26.1rc0+sparkring.native.2160312ffde4`) with the recorded overlay files
bind-mounted; checkpoint files identical to revision `5711b268` except for the
draft configuration's trailing comma, corrected at launch. TP2/DCP1, padded-V
symmetric attention kernel with the split-KV verification dispatch, bf16
target KV and fp8 draft KV, 12 GiB KV reservation per rank, 262,144 configured
context, 16 sequences, 8,192-token batches, 5-token DFlash draft, 32-token
capture ceiling, image 3 / video 1 / audio 1, RoCEnante one-shot all-reduce.

Workload, run from rank 0 against the local API: one 600-token
single-stream decode; eight concurrent distinct prompts of about 8K tokens
each decoding 300 tokens (aggregate output rate); one cold 49,058-token
prefill and one cold 122,658-token prefill, each followed by a 299-token
decode; a 1,500-token generation at greedy and at temperature 1.0 with top-p
0.95, scored by the longest repeated 8-gram run (1 means no repeat). One image
request (solid-color square) and one audio request were checked for a correct
answer. Repeated baselines on this pair vary by about 3 percent single-stream
and 5 percent at C8.

| RoCEnante, 16,384-token batches | 35.7 | 95.5 | 1,908 / 32.0 | 1,486 / 31.0 | 2 / 1 |

Engine-reported KV capacity: 547,326 tokens at the 12 GiB reservation with
multimodal inputs enabled (`GPU KV cache size: 547,326 tokens`). The log
line `RoCEnante all-reduce is live` confirms the transport; NCCL handles
all-reduces above 2 MiB.

Draft lengths 4 and 5 are within noise of each other; 7 is slower. The
16,384-token batch gives no prefill gain. The b12x MoE A16 switch does not
apply to the MXFP4-in-fp8 MoE method this checkpoint uses.

## Limitations

- Single runs; no confidence bounds. Prefill and decode use one prompt each.
- The overlay bypasses the image's attestation entrypoint.
- Video input is enabled but was not exercised.
- Host memory, not device memory, bounds the KV reservation on this pair;
  a 22 GiB reservation triggered the hosts' out-of-memory killer.
