# GLM-5.3 Jovian Judgement r7-compatible GB10 image smoke verification

Status: **implemented and TP4 smoke-verified**, not generally qualified. The
latency observations are **research-only**. Soak behavior is **unsupported** by
this record.

## Conditions

Four NVIDIA GB10 systems served GLM-5.3 Flash at TP4/DCP1/PP1 with seven-token
external DFlash speculation. The target was
`local-inference-lab/GLM-5.3-Flash-NVFP4@520de24eabf507659eaef7c70f14fd584527facc`.
The external draft was
`incoai/GLM-5.3-Flash-DFlash2@dc77ff1c99eeb2df044ee3d4f0094eb033fee410`,
whose weights are BF16.

The base image was
`ghcr.io/fujitsupolycom/sparkring-glm53-runtime@sha256:11922064b342de1fc98f0ef85e6648843c8fa7eb3e4f4353c6ad82d6e457dde0`.
The SparkCache image was
`ghcr.io/fujitsupolycom/sparkring-glm53-sparkcache@sha256:f012dd915c0fff0be384820c2d72cd015b83b9b33c3f980445dd718a807cd0c5`.
[`validation.json`](../../receipts/glm53-flash/jj-r7-gb10-tp4-smoke-20260830/validation.json)
binds their local image IDs and exact vLLM, B12X, SparkCache, NCCL, target, and
draft identities.

## Measurement

The base-image check sent four concurrent strong-oracle requests requiring the
exact one-word responses `red`, `blue`, `green`, and `black`.

The SparkCache check sent the same four semantic lanes to an empty persistent
namespace. Every rank created four manifests and a successful one-shot clear
marker. Every rank reported 605,690,671 bytes for the resulting root geometry.
All four processes were then replaced without deleting their cache roots. One
small inference delivered worker manifest inventory to the scheduler before
the four stored requests were repeated.

## Result

- The base image returned all four exact outputs. Client elapsed time ranged
  from 3.30 to 7.83 seconds.
- Fresh SparkCache publication returned all four exact outputs and created the
  four expected manifests per rank.
- After restart and the readiness inference, all four requests returned exact
  output and used external restore. Client elapsed time ranged from 0.561595 to
  1.582937 seconds; worker cache-service time ranged from 277 to 394 ms.
- The external-hit ratio for the measured restart cohort was 100%.

The machine receipt records the three client-result SHA-256 values.

## Conclusion

The two immutable public images are implemented and TP4 smoke-verified for the
exact C4 cases above. The SparkCache image preserves exact response semantics
across full process replacement for four complete stored roots.

## Limitations

These checks do not establish general qualification, throughput, latency
variance, long-context capacity, fault recovery, or a production service-level
objective. No soak or alternate topology was measured. The four stored roots
were full snapshots, so this record makes no shared-base read claim.
