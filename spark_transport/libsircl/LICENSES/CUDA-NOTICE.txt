embeds them in the library. The packs contain object code generated from CUDA Toolkit headers
(cuda_fp16.h, cuda_bf16.h and cuda_fp8.h, included by kernels/sircl_fold.cu, and nvcc's implicit device
headers). In a built library that object code is distributed under the NVIDIA CUDA Toolkit End User
